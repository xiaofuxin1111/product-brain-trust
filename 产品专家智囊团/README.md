# 产品专家智囊团（Product Brain Trust）

**版本：v1.0.0**（2026-11-06）

帮零产品经验、零编程经验的普通人，在动手用 AI 编程做产品之前，把想法先聊清楚的一个 WorkBuddy skill。

## 它是干什么的

用户带着一个产品想法进来（想做 AI 工具、小程序、网站、小产品……），skill 扮演一位几十年经验的产品专家，通过问答陪他把想法过一遍七道检查：

1. 解决谁的麻烦，具体什么麻烦
2. 你为什么觉得有人要
3. 他愿不愿意换
4. 他会不会再来
5. 第一版的功能能砍到多小
6. 这事怎么养活自己（自己用、不图钱的产品走 B 路，不问付钱）
7. 这款产品最有可能死在哪

聊完产出一份**产品体检单**（最多三个"必须先补"的缺口，每个缺口带具体解决方法）；用户要时再生成一页纸**《产品需求文档》**，可直接复制给 AI 编程工具开工。

## 知识底座

六本产品经典书蒸馏出的 **44 条判定项**（每条七字段：判定什么 / 过关信号 / 不过关信号 / 小白版问法 / 答不上来怎么引导 / 常见误判 / 怎么解决）：

《The Mom Test》《上瘾》《俞军产品方法论》《人人都是产品经理》《启示录》《用户体验要素》

知识层对用户完全不可见——用户只经历人话对话，永远不知道背后是哪本书。

## 安装

解压 zip 到 `~/.workbuddy/skills/`，或把整个 `product-brain-trust` 文件夹放进该目录，重启 WorkBuddy 后生效。

## 目录结构

```
product-brain-trust/
├── SKILL.md                  # 入口：触发条件、运行规则、模块路由表
├── README.md
├── references/
│   ├── 对话脚本.md           # 全场对话唯一台词本（运行优先级最高）
│   └── 蒸馏/                 # 44 条判定项，8 份文件
└── docs/                     # 项目文档（不上传分发包）
    └── 需求共识.md
```
